### 🚀 Fitur Baru & Peningkatan (What's New)

1. **Penyelarasan Antarmuka 100% Mockup Prototype (`resources/views/admin/dashboard.php`):**
   - Merombak total layout dashboard admin menjadi layout dua kolom presisi mengacu pada `CamHub — Dashboard Admin.png`:
     - Sidebar Navy Gelap (`#0c192c`) dengan logo CamHub, navigasi 7 modul admin aktif, identitas Super Admin, dan tombol Keluar Sesi.
     - 4 Kartu Metrik Operasional Ringkas: *Menunggu Verifikasi KYC*, *Unit Inspeksi*, *Transaksi Hari Ini*, dan *Denda Pending*.
     - Grafik batang visual dinamis *Transaksi 7 Hari Terakhir* berwarna biru `#2563eb`.

2. **Modul Verifikasi Dokumen KYC Pengguna (`resources/views/admin/kyc.php`):**
   - Antarmuka inspeksi berkas KTP dan foto selfie wajah pengguna secara visual dengan zoom preview.
   - Filter tab status: *Semua Pengajuan*, *Menunggu Verifikasi*, *Disetujui*, dan *Ditolak*.
   - Aksi 1-klik Persetujuan (*Approve*) yang langsung menyinkronkan status akun pengguna menjadi `kyc_verified = 1`.
   - Aksi Penolakan (*Reject*) dengan modal input alasan penolakan wajib untuk panduan perbaikan pengguna.

3. **Modul Transaksi, Sengketa Escrow, & Pencairan Dana Mitra (`resources/views/admin/transactions.php`):**
   - **Arbitrasi Sengketa Escrow (Dispute Resolution):**
     - Opsi `force-release`: Melepaskan dana tertahan langsung ke saldo toko mitra jika komplain pengguna tidak terbukti.
     - Opsi `force-refund`: Mengembalikan dana penuh ke rekening pelanggan jika terjadi kelalaian mitra penyedia.
   - **Persetujuan Penarikan Dana Mitra (Withdrawals):**
     - Admin dapat menyetujui (*processed*) transfer bank mitra atau menolak (*rejected*) permohonan yang tidak valid.
   - **Tabel Transaksi Menyeluruh:** Memantau seluruh riwayat transaksi sewa dan jual beli lintas toko di platform.

4. **Pengawasan Jadwal Unit Kamera Lintas Mitra (`resources/views/admin/schedule.php`):**
   - Mengawasi seluruh nomor seri fisik kamera (`serial_number`), nama toko mitra pemilik, dan status operasional (`available`, `rented`, `maintenance`).
   - Menampilkan kalender tanggal sewa aktif untuk mencegah manipulasi ketersediaan unit.

5. **Manajemen Penegakan Denda Operasional (`resources/views/admin/fines.php`):**
   - Formulir penerbitan denda resmi: Keterlambatan Pengembalian (`late_return`), Kerusakan Fisik Unit (`damage`), dan Aksesori Hilang (`missing_accessory`).
   - Tabel denda operasional dengan tombol pelunasan status denda dari `pending` menjadi `paid`.

6. **Pusat Pengaturan Pengguna & Log Audit Keamanan (`resources/views/admin/settings.php`):**
   - Tabel kontrol status akun (*Active* / *Suspended*) untuk seluruh pengguna platform dengan proteksi anti-lockout Root Admin ID 1.
   - Penayangan 50 baris riwayat terkini aktivitas sistem pada tabel `audit_logs` secara transparan.

7. **Pembaruan Backend Architecture (`AdminRepository` & `AdminService`):**
   - Menambahkan 16 metode kueri data administratif dan pemrosesan transaksi berorientasi keamanan.
   - Menjamin isolasi transaksi atomik ACID MySQL InnoDB (`beginTransaction` / `commit` / `rollBack`) pada seluruh operasi pembaruan status finansial dan KYC.
   - Perekaman otomatis setiap aksi administratif ke tabel `audit_logs`.

8. **Pendaftaran 12 Rute Web Terproteksi Super Admin (`routes/web.php`):**
   - `GET  /dashboard/admin` -> `AdminDashboardController::index`
   - `GET  /dashboard/admin/kyc` -> `AdminDashboardController::kyc`
   - `POST /dashboard/admin/kyc/{id}/approve` -> `AdminDashboardController::approveKyc`
   - `POST /dashboard/admin/kyc/{id}/reject` -> `AdminDashboardController::rejectKyc`
   - `GET  /dashboard/admin/transaksi` -> `AdminDashboardController::transactions`
   - `POST /dashboard/admin/transaksi/dispute/{id}` -> `AdminDashboardController::resolveDispute`
   - `POST /dashboard/admin/transaksi/withdrawal/{id}` -> `AdminDashboardController::processWithdrawal`
   - `GET  /dashboard/admin/jadwal` -> `AdminDashboardController::schedule`
   - `GET  /dashboard/admin/denda` -> `AdminDashboardController::fines`
   - `POST /dashboard/admin/denda` -> `AdminDashboardController::storeFine`
   - `POST /dashboard/admin/denda/{id}/bayar` -> `AdminDashboardController::payFine`
   - `GET  /dashboard/admin/pengaturan` -> `AdminDashboardController::settings`
   - `POST /dashboard/admin/pengaturan/user/{id}/toggle-status` -> `AdminDashboardController::toggleUserStatus`
