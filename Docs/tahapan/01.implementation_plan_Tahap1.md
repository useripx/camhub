## 03. Analisis Teknis & Pilihan Solusi (Trade-Offs)

### 03.01 Mekanisme Routing Native
- **Opsi A (Dipilih & Diimplementasikan): Front-Controller dengan `.htaccess` URL Rewrite**
  - *Kelebihan:* Menghasilkan URL bersih dan rapi (`camhub.test/`, `camhub.test/katalog`), ramah SEO, dan sesuai standar web modern tanpa framework.
  - *Kekurangan:* Bergantung pada modul `mod_rewrite` Apache (aktif secara default di Laragon).
- **Keputusan:** Mengadopsi **Opsi A** dengan router native yang bersih dan aman di `app/Core/Router.php`.

### 03.02 Keamanan Web Root Laragon
- **Opsi A (Dipilih & Diimplementasikan): Document Root Terisolasi di `public/`**
  - *Kelebihan:* File inti (`app/`, `config/`, `.env`, `storage/`) berada di luar jangkauan HTTP publik langsung sehingga mencegah kebocoran kode sumber.
  - *Kekurangan:* Membutuhkan pengarah `.htaccess` pada root untuk akses via subfolder `localhost/camhub/`.
- **Keputusan:** Mengadopsi **Opsi A** dan melengkapi berkas `.htaccess` di root proyek sebagai jembatan fleksibel.
